How the second reading reuses audio

1 · Separate word recording

Pass 1 says “Number N”, then plays the word’s British dictionary recording. After 650 ms, the same word recording plays again.

2 · Reuse when available

Pass 2 rewinds the same loaded stream when available. Data usage depends on browser caching. Slower uses playbackRate 0.72 with pitch preserved.

3 · Honest estimates

Remote hosts and browser caches can vary. Byte values here are planning estimates, not a promise of a particular mobile bill. Open issue #92 for the public audit trail.
