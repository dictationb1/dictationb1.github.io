## Security notes

- No compromised PIN, seeded verifier, nonempty `adminPin`, raw `sk_`/`ghp_` token, or public vault ciphertext ships in tracked text files.
- Student playback cannot call ElevenLabs. Admin generation/publish requires an unlocked lecturer session and a GitHub token kept only in that tab.
- Headless/jsdom/file QA never accesses live ElevenLabs/GitHub/Youdao providers; external requests are aborted or mocked.

## Not certified

- Real ElevenLabs pronunciation/credit behavior and live GitHub publishing are exercised only with mocks. Committed clips must be generated by the lecturer with their own key; QA does not fabricate audio.
